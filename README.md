
# Travel Agency - Python (OOP, modular)
Proyecto transcrito desde PSeInt a Python (orientado a objetos), modular y optimizado.
Archivos:
- main.py: punto de entrada y flujo general.
- menus.py: funciones para mostrar y validar menús.
- flights.py: clases y lógica para vuelos locales.
- packages.py: clases y lógica para paquetes internacionales (vuelos+hospedaje+comida+actividades).
- payments.py: lógica de pago en efectivo y con tarjeta (simulada).
- card.py: clase CardAccount para manejar saldo y operaciones.
- utils.py: utilidades (validaciones, helpers).

Ejecutar:
python3 main.py
